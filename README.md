# Java Calculator

A console-based calculator application developed in Java to perform basic arithmetic operations and numerical calculations. The project demonstrates the practical implementation of fundamental Java programming concepts.

## Features

- Addition, subtraction, multiplication, and division
- Square and cube calculations
- Interactive operation selection
- User input through the `Scanner` class
- Division-by-zero validation

## Technologies Used

- **Programming Language:** Java
- **Development Environment:** Visual Studio Code

## Java Concepts Used

- **Variables and Data Types** — storing numbers and operation choices using `int` and `double`.
- **Methods** — creating reusable methods for arithmetic operations.
- **Parameters and Arguments** — passing values to methods for calculations.
- **Return Types** — returning calculation results using `int` and `double`.
- **Type Casting** — converting an integer to `double` to support decimal division.
- **User Input** — accepting input through the `Scanner` class.
- **Conditional Statements** — using `if`, `else if`, and `else` to execute selected operations.
- **Input Validation** — checking for division by zero and invalid operation choices.
- **Basic Arithmetic Operators** — using `+`, `-`, `*`, and `/`.

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- A terminal or command prompt

### Installation and Execution

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd java-calculator
   ```

3. Compile the program:

   ```bash
   javac Calculator.java
   ```

4. Run the application:

   ```bash
   java Calculator
   ```
